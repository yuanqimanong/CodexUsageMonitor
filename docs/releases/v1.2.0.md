v1.2.0 新增本机会话速度与 Token 面板，并修复双屏显示和边缘吸附问题。

## 本次更新

- 会话页只显示正在运行的主会话，名称跟随 Codex 侧栏更新，过滤已删除和已归档的会话。
- 每张卡片显示最近一次模型调用的 Token/s，以及输入、缓存输入、输出和思考输出的累计值。
- 额度与会话页统一宽度和卡片排版，三套主题采用不透明底色。
- 一到五条会话自适应高度，超过五条时滚动；屏幕高度不足时也可滚动查看。
- 修复不同缩放比例的双屏之间移动后，半圆变形、面板过大和文字挤压的问题。
- 展开卡片拖过屏幕边缘后，松手即可吸附收起；保留半圆向内拖离和悬停展开。

## 下载与更新

Windows 10/11 x64 用户下载 `CodexUsageMonitor-windows-x64.zip`，完整解压后运行 `CodexUsageMonitor.exe`。更新前先从托盘退出旧程序，再替换文件；原有设置会保留。

需要 Codex 插件时下载 `codex-usage-monitor-plugin.zip`。单独的 `CodexUsageMonitor.exe` 与两个压缩包均提供在附件中，`SHA256SUMS.txt` 用于校验下载文件。

## 已知限制

- 当前产物未做代码签名，Windows 可能显示 SmartScreen 提示。请核对下载来源和 SHA-256。
- 速度在模型调用完成后更新；连续五分钟没有新日志的会话可能暂时隐藏。
- 本机 150%/100% 双屏及 39 项回归检查已通过；第二台 Windows 电脑的完整桌面验收尚未执行。
